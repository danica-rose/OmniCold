Three Roles

Each participant has a specific function in the shipment lifecycle

Shipper
Creates shipments, sets thresholds, confirms delivery. Receives slashed bonds on breach.
Provider
Deposits USDC bond as service guarantee. Bond released on successful delivery.
Oracle
Reports IoT temperature readings on-chain. Triggers automatic breach detection.

Shipment Lifecycle

Irreversible state machine enforced by the smart contract

Created
Shipper defines temperature bounds, participants, and bond amount
Active
Provider deposits USDC bond. Monitoring begins. Oracle reports temperatures.
Monitoring
Each reading is evaluated against min/max thresholds in real-time
Delivered (Success)
Shipper confirms delivery. Full bond returns to provider.
Breached (Penalty)
Temperature exceeds threshold. Bond automatically slashed to shipper.
