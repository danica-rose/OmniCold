Three Roles

Each participant has a specific function

Shipper
Creates shipments, sets thresholds, confirms delivery. Receives slashed bonds.
Provider
Deposits USDC bond as guarantee. Bond released on successful delivery.
Oracle
Reports IoT temperature readings. Triggers automatic breach detection.

Created

Active
Provider deposits bond. Monitoring begins.
Monitoring

Delivered

Breached
Bond slashed to shipper
